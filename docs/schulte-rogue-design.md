> 状态：MVP 已定稿（可开发）  
> 变体 ID（拟定）：`schulte-rogue`  
> 暂定显示名：方格远征  
> 关联仓库：schulte-ultimate  
> 最后更新：2026-08-21

本文档供后续 Agent / 开发直接对照实现，修改玩法时请同步更新本文。

---

## 1. 一句话目标

在一局 **Run** 里连续挑战多张「规则会被遗物改写」的舒尔特方格；用 **时限** 制造日常压力，用 **专注力** 作为整局命数，走到第 8 层（含 Boss）或中途失败后结算。

经典「舒尔特方格 / 方格测试」**保持不变**；本玩法为独立变体入口。

## 2. 已锁定的产品决策

| 决策项 | 结论 |
|--------|------|

| 经典模式 | 不动；榜与 attempt 逻辑分离 |
| 名称 | 暂定「方格远征」，可改 |

## 3. 与经典模式对照

| | 经典方格测试 | 方格远征（肉鸽） |
|--|--|--|
| 目标 | 单局最快 | 本趟走多远 / 是否通关 |
| 规则 | 固定 1→N | 遗物叠加改写 |
| 失败 | 无「局命」，可反复开局 | 专注力归零或放弃 → Run 结束 |
| 存档 | 每次 attempt | Run 结算一条（+ 可选层内记录） |
| 排行 | 今日/总榜 | 远征专榜（最远 / 通关 / 平均层数） |

---

## 4. 核心循环

```
开始远征
  → 初始化：专注力、空遗物栏、第 1 层
  → 【层战斗】按当前修饰规则完成方格
  → 成功 → 三选一遗物（或等价奖励）→ 进入下一层
  → 失败（见资源规则）→ 扣专注 / 重试策略 → 专注归零则结算
  → 第 8 层 Boss 成功 → 通关结算
  → 展示结算页（层数、用时、点错、遗物列表、NPC 评语）
```

层间可继续使用现有虹膜切换动效；入口走小岛手机菜单 /「其他测试」。

## 5. 双资源设计

### 5.1 职责分工

| 资源 | 职责 | 玩家体感 |
|------|------|----------|
| **时限** | 主压力：慢、犹豫、被干扰 | 几乎每层都有 |
| **专注力** | Run 命数：硬伤与超时后果 | 掉光才整局结束 |

说明：经典模式下点错很少，故专注力**不能只绑点错**，必须有其它扣减来源。

### 5.2 MVP 规则（实现按此）

1. 每层有 **层时限**（随层收紧；遗物可加减）。
2. **超时**：本层失败，**专注力 −1**；MVP 采用「扣血后可再开本层」或「直接进入结算」二选一——默认建议：**扣 1 专注后允许重开本层**（更肉鸽）；若手感太拖可改为超时直接结算离场。
3. **点错**：**专注力 −1**（少见但要疼）。
4. **专注力归零**：Run 结束，进入结算。
5. 遗物分两类改数值：**沙漏类（时限）**、**茶/护盾类（专注）**。

### 5.3 UI

- 战斗 HUD 并排展示：沙漏（剩余秒）+ 专注（心/叶子数量）。
- 文案偏 NPC，少开发黑话。

### 5.4 平衡注意

- 避免「超时又狂扣血又立刻死」三重叠；超时以 **先扣专注** 为主惩罚。
- 点错与超时不要在同一帧重复结算两次致命伤害（实现时做互斥或合并）。

## 6. 八层结构（MVP）

**原则（已定）：** 当前 8 层 **最高 6×6**，不引入 7×7 / 8×8。难度提升优先靠：

1. **时限收紧**
2. **方块重排（移动感）**
3. **颜色干扰变吵**
4. **点序改变（如倒序）**

网格只从 3→4→5→6 温和上升。以后做 **10 层+** 再考虑引入 7 / 8。

| 层 | 类型 | 网格 | 时限（基） | 本层固定干扰 |
|----|------|------|------------|--------------|
| 1 | 普通 | 3×3 | 16s | 无 |
| 2 | 普通 | 4×4 | 26s | 无 |
| 3 | 普通 | 4×4 | 紧 20s | 纯时限加压 |
| 4 | 精英 | 5×5 | 34s | 颜色变吵 |
| 5 | 普通 | 5×5 | **30s** | 轻量重排（雾气搅动；「聚光雾」遗物另算） |
| 6 | 普通 | 5×5 | 紧 26s | 点对后重排 |
| 7 | 精英 | 6×6 | 40s | 变色 + 更勤重排 |
| 8 | Boss | **6×6** | 36s | 倒序 + 变色 + 重排 |

默认点对后格子**不消失**；「消格袋」遗物才消失。「仙灵剪刀」开局自动消前几个数。

## 7. 遗物系统

### 7.1 定位

遗物改的是 **「怎么点格子」**，不是养成堆攻击力。

### 7.2 类型

1. **增益 buff**：变简单；普通几乎无代价，**稀有必须带难度税**（扣时限 / 扣专注 / 附带干扰）  
2. **减益 debuff**：变难，但给时限或专注补偿，让人愿意赌  
3. **险注 risk**：自己扛风险换抽卡优势等  

视野 / 节奏 / 资源仍是效果手段，但选卡时以 buff / debuff / risk 标签呈现。

### 7.3 选择流

- 清关后 **三选一**。
- MVP 可不做「跳过」；若做跳过，需有弱补偿或无补偿（避免强跳）。
- 同时生效遗物建议上限（如 6），超出需替换（二期也可）。

### 7.4 MVP 遗物池

| 名称 | 倾向 | 效果摘要 | 稀有度 |
|------|------|----------|--------|
| 放大镜 | 增益 | 下一格轻微提示 | 普通 |
| 镇定茶 | 增益 | 专注 +1 | 普通 |
| 小沙漏 | 增益 | 时限 +6s | 普通 |
| 聚光雾 | 增益 | 只亮当前目标（易定位）；时限 −8s | **稀有** |
| 消格袋 | 增益 | 点对消失；时限 −8s | **稀有** |
| 仙灵剪刀 | 增益 | 开局消 3 个数；时限 −10s 且 −1 专注 | 稀有 |
| 大沙漏 | 增益 | 时限 +12s，但颜色变吵 | 稀有 |
| 专注叶 | 增益 | +1 专注、+5s，但附带轻量重排 | 稀有 |
| 万花筒 | 减益 | 颜色变吵；补偿 +8s | 普通 |
| 倒走表 | 减益 | N→1；补偿 +12s | 稀有 |
| 地震 | 减益 | 勤重排；补偿 +1 专注、+6s | 稀有 |
| 赌徒骰 | 险注 | 点错 −2 专注，稀有更好刷 | 稀有 |

「聚光雾 / 消格袋」属于强桌面增益，禁止做成普通无代价。

## 8. 失败与结算

### 8.1 结束条件

- 专注力 ≤ 0  
- 玩家主动放弃  
- 第 8 层胜利（通关）

### 8.2 结算页展示

- 结果：通关 / 倒下在第 N 层  
- 总用时、总点错、剩余专注  
- 本趟遗物列表  
- 一句 NPC 评语  

### 8.3 数据（MVP）

- `variant_id`: `schulte-rogue`（最终以 registry 为准）  
- 写入一条结算记录（可复用 `submit_attempt` + 丰富 `meta`，或后续专用表）  
- `meta` 建议字段：`layersCleared`, `focusLeft`, `relics[]`, `totalWrong`, `won`, `seed`  
- 排行：`fetch_rogue_leaderboard`（最远层 → 同层用时；通关最快；平均层数）  
- 经典 `fetch_leaderboard` **不混入**肉鸽成绩

经典榜与肉鸽数据隔离，禁止混进「最佳用时」总榜。

## 10. MVP 范围

### 做

1. Registry 新变体 + 入口  
2. Run 状态机：层 → 战斗 → 选遗物 → 下层 / 结算  
3. 时限 + 专注力 HUD 与结算规则  
4. 8 层配置表 + 简单精英/Boss  
5. 8～12 遗物 + 三选一  
6. 结算入库（个人可见即可）  
7. 远征专榜（与经典用时榜隔离）  

### 不做（二期+）

- 岛币商店、多角色、好友同种子  
- 无尽、复杂分支地图  
- 完整遗物图鉴收集系统
