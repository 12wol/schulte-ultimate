## 1. 一句话目标

在一局 **Run** 里连续挑战多张「规则会被遗物改写」的舒尔特方格；用 **时限** 制造日常压力，用 **专注力** 作为整局命数，走到第 8 层（含 Boss）或中途失败后结算。

经典「舒尔特方格 / 方格测试」**保持不变**；本玩法为独立变体入口。

|--------|------|

## 3. 与经典模式对照

| | 经典方格测试 | 方格远征（肉鸽） |
|--|--|--|
| 目标 | 单局最快 | 本趟走多远 / 是否通关 |
| 规则 | 固定 1→N | 遗物叠加改写 |
| 失败 | 无「局命」，可反复开局 | 专注力归零或放弃 → Run 结束 |
| 存档 | 每次 attempt | Run 结算一条（+ 可选层内记录） |
| 排行 | 今日/总榜 | MVP 不做 |

## 4. 核心循环

```
开始远征
  → 初始化：专注力、空遗物栏、第 1 层
  → 【层战斗】按当前修饰规则完成方格
  → 成功 → 三选一遗物（或等价奖励）→ 进入下一层
  → 失败（见资源规则）→ 扣专注 / 重试策略 → 专注归零则结算
  → 第 8 层 Boss 成功 → 通关结算
  → 展示结算页（层数、用时、点错、遗物列表、NPC 评语）
```

层间可继续使用现有虹膜切换动效；入口走小岛手机菜单 /「其他测试」。

## 5. 双资源设计

### 5.1 职责分工

| 资源 | 职责 | 玩家体感 |
|------|------|----------|
| **时限** | 主压力：慢、犹豫、被干扰 | 几乎每层都有 |
| **专注力** | Run 命数：硬伤与超时后果 | 掉光才整局结束 |

说明：经典模式下点错很少，故专注力**不能只绑点错**，必须有其它扣减来源。

### 5.2 MVP 规则（实现按此）

1. 每层有 **层时限**（随层收紧；遗物可加减）。
2. **超时**：本层失败，**专注力 −1**；MVP 采用「扣血后可再开本层」或「直接进入结算」二选一——默认建议：**扣 1 专注后允许重开本层**（更肉鸽）；若手感太拖可改为超时直接结算离场。
3. **点错**：**专注力 −1**（少见但要疼）。
4. **专注力归零**：Run 结束，进入结算。
5. 遗物分两类改数值：**沙漏类（时限）**、**茶/护盾类（专注）**。

### 5.3 UI

- 战斗 HUD 并排展示：沙漏（剩余秒）+ 专注（心/叶子数量）。
- 文案偏 NPC，少开发黑话。

### 5.4 平衡注意

- 避免「超时又狂扣血又立刻死」三重叠；超时以 **先扣专注** 为主惩罚。
- 点错与超时不要在同一帧重复结算两次致命伤害（实现时做互斥或合并）。

## 7. 遗物系统

### 7.1 定位

遗物改的是 **「怎么点格子」**，不是养成堆攻击力。

### 7.2 类型

1. **视野类**：下一数提示、短暂全图、边缘模糊等  
2. **规则类**：倒序、只点奇数、双色过滤等  
3. **节奏类**：点对后洗牌、周期重排等  
4. **风险类**：点错多扣、换更好奖励等  
5. **资源类**：加减时限 / 专注上限或回复  

### 7.3 选择流

- 清关后 **三选一**。
- MVP 可不做「跳过」；若做跳过，需有弱补偿或无补偿（避免强跳）。
- 同时生效遗物建议上限（如 6），超出需替换（二期也可）。

### 7.4 MVP 遗物池（先做 8～12 个）

| 名称 | 效果摘要 | 稀有度 |
|------|----------|--------|
| 放大镜 | 正确下一格轻微提示 | 普通 |
| 倒走表 | 之后改为 N→1 | 稀有 |
| 万花筒 | 颜色干扰增强 | 普通 |
| 地震 | 每点对若干个后全盘重排 | 稀有 |
| 镇定茶 | 专注 +1（或回 1） | 普通 |
| 小沙漏 | 本层及之后层时限 +X 秒 | 普通 |
| 赌徒骰 | 点错额外 −1 专注，通关多一次抽卡 | 稀有 |
| 迷雾 | 未点区域变暗 | 普通 |
| 双倍眼镜 | 同时追两个序数（偏难，可放精英后） | 史诗 |
| Boss 主题包 | 仅第 8 层：复合规则（倒序+重排等） | Boss |

具体数值表实现时落在代码常量，并回写本节。

## 8. 失败与结算

### 8.1 结束条件

- 专注力 ≤ 0  
- 玩家主动放弃  
- 第 8 层胜利（通关）

### 8.2 结算页展示

- 结果：通关 / 倒下在第 N 层  
- 总用时、总点错、剩余专注  
- 本趟遗物列表  
- 一句 NPC 评语  

### 8.3 数据（MVP）

- `variant_id`: `schulte-rogue`（最终以 registry 为准）  
- 写入一条结算记录（可复用 `submit_attempt` + 丰富 `meta`，或后续专用表）  
- `meta` 建议字段：`layersCleared`, `focusLeft`, `relics[]`, `totalWrong`, `won`, `seed`  
- **不上排行榜 RPC / 榜页面**

经典榜与肉鸽数据隔离，禁止混进「最佳用时」总榜。

## 10. MVP 范围

### 做

1. Registry 新变体 + 入口  
2. Run 状态机：层 → 战斗 → 选遗物 → 下层 / 结算  
3. 时限 + 专注力 HUD 与结算规则  
4. 8 层配置表 + 简单精英/Boss  
5. 8～12 遗物 + 三选一  
6. 结算入库（个人可见即可）  

### 不做（二期+）

- 肉鸽排行榜  
- 岛币商店、多角色、好友同种子  
- 无尽、复杂分支地图  
- 完整遗物图鉴收集系统

## 11. 技术落点（实现指引）

| 区域 | 建议 |
|------|------|
| 注册 | `src/variants/registry.ts` 增加 `schulte-rogue` |
